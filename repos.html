Arch-scripts

arch-scripts, a CLI tool made in python, to do various things on arch-linux easily. For instance, updating system, configuring thing and installing pacman packages bundles. This software aims to ease software modification and installation on arch linux.

BetterYoutube

BetterYoutube is a desktop youtube client for both windows and linux. It is built on electron, and is packed with features, like built-in adblocker, and userscripts. Though, it is no longer maintained by me. So, if you want to improve it, do it yourself by forking the repository.
